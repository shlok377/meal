# Use React Three Fiber with Vite and Tailwind CSS for 3D Meal Showcase

We chose Vite + React + React Three Fiber (@react-three/fiber and @react-three/drei) alongside Tailwind CSS and Framer Motion for the landing page. This architecture cleanly separates the 3D WebGL render loop from declarative React state, enabling seamless theme transitions, camera animation synchronization, and responsive editorial overlay positioning without boilerplate WebGL lifecycle management.
